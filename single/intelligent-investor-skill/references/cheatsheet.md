# 决策规则速查 — 聪明的投资者（第4版，注疏点评版）

| 能力 | 一句话规则 |
|---|---|
| 投资者类型自测与投机隔离 | 先按时间/精力/性格把自己分到防御或积极通道；投机资金单账户≤10% |
| 股债25%~75%配置与再平衡纪律 | 股债标准对半开，区间25%~75%，每6个月或比例越界5个百分点时再平衡 |
| 市场整体估值检查 | 用组合盈利收益率vs高等级债息、三因子预期回报、PE分级给大盘定贵贱，再给仓位倾向 |
| 市场先生波动应对纪律 | 报价是可拒绝的服务：不因涨买跌卖；暴跌=机会；组合波动预期先按+50%/−1/3备课 |
| 防御型选股：四大规则+七项统计标准 | 七项统计标准+市盈率×市净率≤22.5筛防御组合；分母一律多年平均利润 |
| 安全边际测算与决策（含行为自检） | 盈利能力−债券利率、评估价值−市价（≤2/3）两条口径；缓冲不够就不买，且必须配分散化 |
| 每股收益辨伪与财务红旗 | EPS先过三重检验（单年→7年平均→完全稀释），再对红旗清单（并购成瘾/OPM/客户集中/利息保障不足）逐项打勾 |
| 定投+指数基金自动组合 | 固定金额定期买低成本宽基指数；费用优先核查，然后"我不知道，也不在乎" |
| 格雷厄姆估值：简化公式+两步评估+债券保障倍数 | 价值=当期（正常）利润×(8.5+两倍预期年增长率)当防御性锚；债券按多年利息保障倍数（工业7/5、公用4/3） |
| 积极型三策略（低市盈率大公司/廉价net-net/特殊情况） | 低市盈率大公司、低于净营运资本的廉价股、特殊情况三路；先过积极型资格预检，纸面练兵一年，分散持有 |
| 成对公司比较分析法 | 同业成对比较六维度（盈利/稳定/成长/财务/股息/价格史），回答"质量差是否值价差" |
| 牛市泡沫症状与新股免疫 | 牛市后期信号逐条对照（新股泛滥/质劣量增/破发）；新股热门股默认免疫，方法"只要管用"即警惕 |
| 基金挑选与卖出信号 | 费用→风险→业绩倒序审查；好基金四特征、卖出四信号、3年亏损准备 |
| 可转债与权证怀疑框架 | 转换权必有让步；牛市后期集中发行是警告；权证/期权价值须并入真实市价；永不转换 |
| 股息政策与股东行动 | 支付率约2/3，或证明留存带来满意的EPS增长；盯期权计划与回购价格 |
| 投资顾问尽调 | 先判定是否真需要顾问；再按利益冲突清单（收费结构/托管/承诺收益）尽调 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
