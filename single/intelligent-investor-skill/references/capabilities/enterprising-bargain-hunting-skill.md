# 积极型三策略：低市盈率大公司、廉价证券与特殊情况

## R — 原文

- "一种选择或操作策略必须具备两项优势：（1）它必须能达到基本稳健所要求的客观或合理标准；（2）它必须有别于大多数投资者或投机者采用的策略。"（第7章）
- "我们假设真正的“廉价”证券显示的价值，至少要比其价格高出50%。"（第7章）
- "售价比公司（扣除所有优先债务后）的净营运资本本身还要低。"（第7章，最容易识别的廉价证券）
- "不要按“全价”购买三类重要的证券：（1）外国债券；（2）一般的优先股；（3）二类普通股。……我们定义的低价，是指价格不超过证券评估价值的三分之二。"（第7章）
- "这两类业务的选择以下列两个条件为基础：（1）所计算出的平均回报率在20%及以上；（2）我们认为成功的机会至少达80%。"（第15章）
- "Longleaf公司的霍金斯喜欢寻找他所称的“60分目标”，即当时的股价在评估价值的60%或60%以下的公司。"（第15章点评）

## I — 自述

准入双前提：方法客观稳健、与流行做法不同。三领域：
策略一，低市盈率大公司：买被冷落的大公司，防周期股利润峰值伪装的低市盈率——须相对多年平均利润也便宜。
策略二，廉价证券：价值至少比售价高50%；极端形态net-net＝买价低于扣优先债务后的净营运资本，须群体分散。
策略三，特殊情况（套利、清算）：只做年化≥20%且胜算≥80%的可计算交易。

## A1 — 书中案例

- net-net组合（第7章表7-4）：1957年12月按"价低于每股净流动资产"选85种持两年。结果：组合涨75%（标普425工业+50%），无一严重亏损。
- 低市盈率检验（第7章表7-2）：1936年1万美元按最低市盈率轮换，1962年变66 900美元（高市盈率组25 300）。

## A2 — 触发场景

1. 愿投入大量时间选股，问"比防御型更好的路子"。
2. "市盈率最低的股票能不能买、怎么筛便宜货？"
3. 找到股价低于净营运资本或远低于账面值的标的，问值不值得买。
4. 问套利/清算能不能做，或"该不该当积极型"。
Trigger 词：积极型／enterprising investor／低市盈率／low P/E／bargain／net-net／净营运资本／套利／arbitrage／special situation。
区分：类型自测在前（本卡只含预检）；安全边际测算提供评估价值；防御型标准是另一条路线；成长股投资不在三策略内。

## E — 执行步骤

第0步 预检（判停点）：a) 愿长期投入大量时间精力；b) 接受练兵一年；c) 积极型≠多冒险；d) 预期税前超额＞5%。任一不满足→退回防御/指数路线。
输入契约：候选池的当期与多年平均市盈率、流动资产与负债、债务、近5年利润、股息、有形资产与净营运资本、并购/清算条款；评估价值（估值卡）。
策略一：取大型知名公司中当期市盈率最低的6～10只，剔周期假象（相对过去平均利润同样低）；可叠六项筛选：流动比≥1.5、债务≤净流动资产110%、近5年无赤字、有股息、利润高于10年前、股价≤有形资产120%；等额买入、1～5年换仓。完成标准：清单＋双重便宜证据。
策略二：双标准估值（评估法＋私人所有者价值法）；净流动资产＝流动资产−全部负债（含优先股与长期债务）；廉价判定价值≥价格×1.5，net-net判定买价≤每股净流动资产×2/3；剔当期亏损者，群体分散（通常100种以上）。完成标准：净流动资产表＋名单。
策略三：仅当可计算时参与：年化回报＝价差÷现价×(365÷预计天数)；双门槛年化≥20%且胜算≥80%（无依据→放弃）；逐年跟踪淘汰。完成标准：回报计算＋胜算依据。
通用纪律：三类证券禁全价买（低价≤评估价值2/3）；练兵一年后个股≤组合10%（其余指数基金）；买价目标≤评估价值60%。
输出契约：预检结论＋三策略筛选清单＋纪律检查表。

## B — 边界

1. 防御与积极没有中间态："半个经营者"多半失望（第7章）；预检不过别用。
2. 策略自我衰减：net-net随牛市消失；低市盈率法1968～1971年失效；流行的方法都会失效（第8章）。
3. 特殊情况已专业化：胜算估计靠从业经验，点评明言并购套利对个人不适宜——无计算依据者禁入。
4. net-net近绝迹时用"买价≤评估价值2/3"次优替代；框架对优质成长定价不足（IBM教训，附录4；GEICO属例外）。
5. 成长股投资不在三策略内：45家成长基金十年108%对指数105%。
