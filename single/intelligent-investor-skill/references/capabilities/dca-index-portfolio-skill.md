# 定投＋指数基金自动组合

## R — 原文

1. "最为理想的美元成本平均法是投资于一组指数基金，从而将所有具有投资价值的股票和债券都一网打尽。这样的话，你就可以摆脱诸如预测股市的走向、了解哪些板块以及其中的哪些股票会表现最好之类的猜谜游戏。"（第5章点评）
2. "假定你每个月可结余500美元，你可以借助美元成本平均法拥有三只指数基金。其中300美元投资于美国股票市场指数基金，100美元投资于外国股票指数基金，还有100美元投资于美国债券市场指数基金，这样你就可以确信囊括这个星球上几乎所有值得拥有的投资了。"（第5章点评）
3. "指数基金极低的管理费用（每年0.2%的操作费用，外加每年仅0.1%的交易成本）使其具有不可比拟的优势。"（第9章点评）

## I — 自述

定投（美元成本平均法）就是固定日期投入固定金额：跌的时候同样的钱买到更多份额，涨的时候买到更少——它一次性消灭了两个最容易出错的决策："何时买"和"买哪个板块"。最理想的标的是覆盖全部资产类别的低成本指数基金组合（书中示例：每月结余按60%本国股、20%外国股、20%债券拆分）。建好后组合自动运行，对一切市场问题都回答"我不知道，也不在乎"——因为两类资产你都已持有。费用是最可预测的变量，故为第一筛选条件（指数基金合计约0.3%，一般股票基金每年拖累约3.5个百分点）。纪律配套：无论涨跌照常执行，跌时不停扣，涨时不加码；想自己选股的人最多拿10%仓位实验，核心仍是指数。

## A1 — 书中案例

worked_example（第5章点评，Ibbotson Associates演算）："如果你在1929年9月初，以12 000美元买进标准普尔500指数基金，十年之后你的手中将只剩下7 223美元。但是如果你以区区100美元起步，以后每月追加投入100美元，到1939年8月，你的资金就会增至15 571美元！"输入＝同等总投入的两种进入方式；方法＝按月定额；结果书中即交代：即便买在大萧条最惨十年，定投仍正收益、一次性买入腰斩。配套边界：正文汤姆林森23个十年期检验截止1952年，样本期恰好偏牛（1949年起算），格雷厄姆据此只承认它"防止在错误时间大量买入"，不承认它必赚。

## A2 — 触发场景

1. "每月工资结余该怎么投"——"how to invest monthly savings / 定期定额"。
2. "现在点位这么高，定投要不要等回调再开始"——起投边界问题——"should I wait for a dip to start DCA"。
3. "帮我看看这只指数基金/主动基金该买哪个"——费用核查——"index fund vs active fund 费率"。
4. "定投亏了15%要不要停扣"——纪律问题——"pause DCA when losing"。
5. 区分（初稿）：与股债配置卡不同——本卡管新增现金流的进入方式，存量资金的比例归配置卡；与市场先生卡不同——本卡是自动机制，不做单次涨跌的判断；与防御选股卡不同——本卡默认放弃选股，只在用户坚持选股时给10%实验仓规则。

## E — 执行步骤

输入契约：每月（或每周/每季）可固定投入的金额、发薪/结余日期、可投资年限、现有存量组合与比例、候选基金清单及其年度费率。金额或期限缺失→先问用户，不定假设值。

1. 定标的：一组覆盖全部资产类别的宽基指数基金（本国股票、外国股票、债券三只起步；书中拆分为60%/20%/20%）。完成标准：每只基金列出名称、跟踪指数、费率。
2. 定金额与频率：金额定在"跌两年也不断供"的水平；固定日期设自动转账。完成标准：金额数字＋执行日期写入方案。
3. 费用核查清单：逐一核对——指数基金操作费＋交易成本合计应显著低于主动基金上限（原书2003年上限：美国大中盘股1.0%、小盘1.25%、外国股1.5%；指数典型合计约0.3%）；有销售费/申购费高昂者剔除。完成标准：每只基金费率与上限对照表，超限即换。
4. 纪律条款：无论涨跌照常扣款；不因浮亏停扣、不因大涨加码；愿意者签署投资所有者合约（承诺不因涨买不因跌卖、每次投入至少持有10年，仅限现金紧急需求例外）。完成标准：条款逐条确认为"接受"。
5. 起投边界检查：新开方案前用市场估值卡的结论核对整体水位——市场处极端高位（如希勒PE>20的危险区）时，格雷厄姆提醒不宜新开定投方案（1964年告诫）；已开方案继续执行不受影响。完成标准：留档水位判断结论。

输出契约：定投方案表（标的/比例/金额/频率/执行日）＋费用核查清单结果＋纪律条款确认＋起投边界判断记录。

## B — 边界

1. 定投不承诺盈利或回本：它只避免"在错误时间大量买入"；汤姆林森的23期检验样本期偏大牛市起点，证据本身有幸存偏差，不得引用为"必赚"。
2. 失败模式：频繁交易——巴伯-奥丁66,000账户研究显示，扣除成本后买卖最频繁的两成年收益率落后市场6.4个百分点；停扣于低点等于高买低卖；把定投当摊薄成本必回本的赌注。
3. 费率上限数值为2003年美国市场口径，须按当期市场重标定；其他市场工具映射（宽基ETF、债券基金）由使用者按当地品种落实。
4. 不适用于一次性大额存量资金的配置（那是股债配置卡的任务）；极端高位不宜"新开"方案，但绝不可反向理解为"择时停扣"。
