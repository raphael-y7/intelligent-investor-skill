# 格雷厄姆估值：简化公式、两步评估与债券保障倍数

## R — 原文

- "价值=当期（正常）利润×（8.5+两倍的预期年增长率）"（第11章）；"增长率这一数据应该是随后7～10年的预期增长率。"（同章下句）
- "在华尔街44年的经历和研究中，除了简单的算术和最基本的代数之外，我从未看到过关于普通股价值或相关投资政策的可靠算法。一旦使用微积分或高等代数，你就把它看做是一种警示：操作者在试图以理论代替经验，而且通常也是在试图以投资为幌子而掩盖投机。"（第11章注引格雷厄姆）
- "分析的第二步要考虑，完全以以往业绩为基础的价值，应该根据未来预期的新情况进行多大程度的修正。"（第11章）
- "我们认为，“最差年份”标准可以代替7年平均标准，债券或优先股只要满足其中一个标准即可。"（第11章；表11-1税前7年平均：公用4、铁路5、工业7倍）
- "税前利润与固定费用和两倍优先股股息之和的比值，同样要达到上述标准。"（第11章）

## I — 自述

三件工具，给估值提供锚而非答案。
其一，速算公式：价值＝正常化每股利润×(8.5＋2×预期年增长率)，G取未来7～10年且必须保守；反向用法更有用——由市价解出隐含增长率检验市场预期（增速超8%且无限延续，价值趋于无穷大）。
其二，两步评估：第一步只用历史数据算"以往业绩的价值"；第二步显式判断新情况使价值偏离多少，双值并报。
其三，保障倍数表：按行业对照7年平均（或最差年份）利息保障底线；优先股按固定费用＋两倍优先股股息。
纪律：只承认简单算术，公式越复杂越接近投机。

## A1 — 书中案例

- 表11-2（例题，第11章）：价值线1964年中预测1967～1969年对比1968年实际：联合化学预测3.70美元、实际仅1.46美元。结果：顶尖公司的预测也系统性偏离。
- 表11-5（例题，第11章）：反推1963年市价隐含增长率：施乐32.4%、道指5.1%（高于此前实际3.4%）。结果：施乐、IBM后来接近高增长，但作者提醒"读者不要错误地认为此类预测非常可靠"。

## A2 — 触发场景

1. 问"这只成长股大概值多少钱"。
2. "现价隐含多高增长预期、合理吗"（反推）。
3. 评估债券、优先股或可转债发行人的利息保障。
4. 鉴别复杂量化估值模型。
Trigger 词：估值／valuation／内在价值／intrinsic value／格雷厄姆公式／Graham formula／隐含增长率／implied growth／利息保障倍数／interest coverage。
区分：每股收益辨伪先让EPS可信（输入）；安全边际用本卡输出算差额；成对比较是相对检验，本卡是绝对锚定。

## E — 执行步骤

输入契约：已还原的正常化EPS（剔特殊、完全稀释）、7～10年预期增长率（保守）、当期市价；债券端：7年利润序列（或最差年份）＋总固定费用＋类别。
1. 债券保障倍数：利润÷总固定费用，对照底线（税前7年平均：公用4／铁路5／工业7倍；最差年份3／4／5；税后2.65／3.20／4.30），择一达标；优先股分母加2×优先股股息。完成标准：达标与否＋口径。
2. 公式正向：价值＝EPS×(8.5＋2G)，G保守取值（与过去不同时一律向下）。完成标准：乘数与价值；G≥8%标注"高成长无法可靠估值"。
3. 公式反向：隐含G＝(市价÷EPS−8.5)÷2，对照可持续性（大公司连10年20%增长仅3%）。完成标准：隐含增长率＋评语。
4. 两步评估：第一步纯历史算"以往业绩的价值"；第二步列新情况修正因素与幅度，双值并报。完成标准：双值＋理由；权重书中未给（约定：无法确定时退回公式法，标missing）。
5. 利率检查：写明当期利率；公式未含利率——高利率时乘数下调（约定）。
输出契约：估值卡（EPS口径｜G与理由｜乘数｜评估价值｜市价｜差额%｜隐含增长率｜保障倍数判定）。

## B — 边界

1. 公式基于1970s美国数据：8.5为零增长乘数、未含利率——兹威格提醒按利率环境修正；跨市场保留结构、重标参数。
2. 两步评估的权重书中未给出——标为约定，不得冒充原书规则。
3. G≥8%时公式发散（无穷大悖论）：高成长股只能输出"无法可靠估值＋隐含增长率"，不得输出价格。
4. 复杂模型即警示：出现微积分或高等代数的估值是投机信号。
5. 用于防御性锚定与检验预期而非精确估值——预测常错，结论须配安全边际。
