# GLOSSARY — 《聪明的投资者（第4版注疏点评版）》共享术语词典

> 阶段3产出。所有定义均取自合并转写稿原文（格雷厄姆正文或兹威格点评/注），下游能力卡统一引用本词典口径。完整带引文版本见 `candidates/glossary.md`。

| # | 术语 | 作者定义（要点） | 与常识用法的差异 |
|---|---|---|---|
| g01 | **投资** | 以深入分析为基础，确保本金安全，并获得适当回报；不满足即是投机（第1章引《证券分析》） | 定义针对操作而非资产：同一只股票，取决于价格与依据，可投资可投机。投资者"根据公认的价值标准判断市价"，投机者"根据市价确定价值标准"（第20章：以安全边际为投资/投机的区分标准） |
| g02 | **投机／受控投机** | 不违法、与道德无关，但三种情况不明智：自以为投资、无知识却严肃投机、超额投入（第1章）；受控规则＝单开账户＋≤总资产10%＋当消遣（第1章点评） | ≠ 赌博贬义词。格雷厄姆主张"限制和约束"而非戒绝；保证金交易、抢购热门股均属投机 |
| g03 | **防御型投资者** | 首要目的是避免重大错误或损失，其次是不必付出太多努力和烦恼（导言） | ≠ 只买债券的人／低风险偏好者。防御型仍须持有25%~75%股票；回报由"愿付出的智慧"而非风险决定；判据是时间精力与性格，与年龄无关（第4章点评） |
| g04 | **积极（进取）型投资者** | 愿意为挑选证券付出大量时间和精力，以获取超出平均的回报（导言）；策略须①达基本稳健标准②有别于大众策略（第7章） | ≠ 敢冒险的人／买成长股的人。是"工作量"概念；且与防御型之间**无中间态**——"不可能成为较好的半个经营者"（第7章） |
| g05 | **"聪明"的投资者** | 与IQ/SAT无关：耐心、约束、渴望学习、驾驭情绪、自我反思；"与其说表现在智力方面，不如说表现在性格方面"（导言点评引格雷厄姆） | 反例：牛顿南海泡沫亏2万英镑；长期资本管理（两位诺奖得主）。投资成败取决于性格修养而非智力 |
| g06 | **安全边际** | 使投资者不必对未来做出准确预测的价值缓冲：债券＝利润超出利息要求的能力；普通股＝预期盈利能力大大高于债券利率；廉价证券＝市价低于评估价值的差额（第20章） | ≠ 仓位控制术语，≠"买优质公司"。是价格与价值可量化的差额；"足够低的价格能使质量一般者变成稳健投资"；只提高胜率不保证不亏，必须配分散化（保险逻辑） |
| g07 | **市场先生** | 每天报价的合伙人寓言：情绪在过度乐观与悲观间摆动，你可利用报价或完全不理会；价格波动对投资者只有一个意义——大跌后买入机会、大涨后卖出机会（第8章） | 报价是**可拒绝的服务**而非信息。把"可不理会报价"的基本优势变成"跟风操作"的基本劣势，是投资者最典型的自我毁灭 |
| g08 | **盈利能力** | 现有业务条件下未来若干年（5年或以上）预计可年复一年赚取的利润；可用市盈率倒数近似（11倍PE≈9%）（第20章注2） | ≠ 当期/单年/预测利润。"把当期较高利润当成盈利能力"是投资者主要亏损来源；利息保障须用含差年份的多年口径 |
| g09 | **"风险"双重含义** | 真正的风险＝价值损失（实际售出亏损、公司地位恶化、买价过高）；单是市场价格下跌"并非真正的风险"（第5章） | ≠ 学术Beta/波动率。但双向边界：买价过高即使不动也是真风险；"拿着无风险"只对适当挑选的组合成立 |
| g10 | **廉价证券** | 根据分析确立的事实，价值至少比售价高出50%；积极型买价≤评估价值的三分之二（第7章） | ≠ 低价股/跌得多的股票。是价值差额；成因（当期失望/长期冷落）单独不构成买入条件，还须利润稳定性＋规模与财务实力 |
| g11 | **净流动资产证券（net-net）** | 售价低于公司扣除全部优先债务后的净营运资本——买主没支付固定资产和商誉的价格（第7章）；净营运资本＝流动资产−全部负债（含优先股与长期债务）（第7章注13） | ≠ 破净（破净仍计固定资产）。格雷厄姆-纽曼买价≤净流动资产2/3、≥100只分散；1957年美股约150只，10年内消失——判据本身受稀缺性限制 |
| g12 | **二类企业** | 未在重要行业占据领导地位的企业（第7章）；只能按廉价条件（≤评估价值2/3）购买，不可按全价买 | ≠ 垃圾公司。是定价不对称规则：领头企业股=准控制权股份，二类股须折价买；牛市中被高估的小盘二类股多数永远无法全面反弹（第15章随机股检验） |
| g13 | **成长股** | 每股收益增长显著超平均且预计持续（专家标准：10年翻番=年7.1%）（第5章）；估价公式：价值=当期（正常）利润×(8.5+两倍预期年增长率)（第11章） | 格雷厄姆不否认成长、否认按当期高市盈率买入："预期收益已完全包含在股价中＋未来判断可能错误"双障碍；45家成长基金1961-70跑输指数 |
| g14 | **市盈率（多年平均口径）** | 分母取过去7年平均利润（上限25倍）或12个月利润（上限20倍）（第5章）；防御型：3年平均利润15倍、账面值1.5倍、乘积22.5（第14章）；组合盈利收益率≥高等级债息（第14章） | 分母口径是本质：华尔街用"下一年利润"是被格雷厄姆极力反对的做法；A股软件默认"市盈率(动)"正是该口径，须显式指定多年平均分母 |
| g15 | **账面价值／有形资产价值** | 股东权益减商誉商标等无形资产，按完全稀释股数摊薄（第8章注11）；"最好集中购买高于有形资产价值不超过三分之一的股票"（第8章） | ≠ 报表股东权益。贴资产买入＝价值锚独立于市场情绪；溢价是"为流动性支付的费用" |
| g16 | **商誉与"水分"** | "商誉或未来盈利能力越重要，企业实际价值越不确定，内在投机性越严重"（附录4）；水分从资产负债表转移到了市场估价 | 反直觉推论：越优质（越依赖未来盈利）的股票投机性越强——"普通股的质量越好，其投机的可能性越大"（第8章） |
| g17 | **利息保障倍数** | 利润（多年平均或最差年份）为总固定费用的倍数；投资级最低：公用事业4/3、铁路5/4、工业7/5（税前/税后）；优先股按固定费用+2倍优先股息（第11章表11-1） | ≠ 当期口径。宾州中央1965年即不达标、1970年破产——倍数须"包含经济较差时期"的多年检验 |
| g18 | **美元成本平均法／程式投资** | 每月/季固定金额购股的机械规则（第1章）；属程式投资：股债25%~75%区间反向调整（第1章） | ≠ 含择时的"逢低加仓"。纯机械、不预测；对比：以预测顶部为核心的程式方案因流行而集体失败——"任何容易理解且被广泛采用的赚钱方法都会自我衰减"（第8章）；DCA不承诺正收益，只避免错误时点重仓 |
| g19 | **特殊情况** | 并购套利、清算、对冲等依赖既定交易完成的业务（第1章）；格雷厄姆-纽曼双门槛：年化回报≥20%且成功概率≥80%（第15章） | 属投资而非投机（依据计算而非股价预测）；但已专业化、利润递减——对普通用户基本不可用 |
| g20 | **可转换证券与认股权证** | "你不可能仅仅通过一种巧妙的手段使交易双方都获得好处"——转换权以质量或收益让步为代价（第16章）；权证"凭空捏造价值、纸币畸形物"（第16章） | ≠"下有保底上不封顶"。可转换优先股1968-70平均跌29%＞普通股5%；牛市后期发行的可转债必然收益不佳；权证市值须加回计算"真实市场价"；戒律："永远不要把可转换债券进行转换" |
