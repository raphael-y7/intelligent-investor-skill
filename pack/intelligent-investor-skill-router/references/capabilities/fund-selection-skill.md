# 基金挑选与卖出信号

## R — 原文

- "大多数基金购买者首先看重的是以往的业绩，其次是基金经理的声誉，再次是基金的风险状况，最后（如果还有的话）关注的是基金的费用。聪明的投资者也是观察这些东西，但其顺序正好相反。"（第9章点评）
- "因为基金的费用比其未来的风险或回报更容易预测，所以你应该将其作为第一个筛选条件。"随后给出年度操作费用上限：美国大中盘股1.0%、小盘1.25%、外国股票1.50%。（第9章点评）
- "共同基金股份的投资者可以适当地比较过去某一时期（比如至少5年内）的业绩，只要这些数据并没有代表整个市场大幅向上的趋势。"（第9章）
- "如果你想把钱投入投资基金，就按一定的折扣（比如资产价值10%～15%的折扣）购买一组封闭式基金股份，而不要按高于资产价值9%的费用去购买开放式基金公司的股份。"（第9章）
- 卖出信号："在此，有几个确定的信号：交易策略突然发生急剧改变……费用上升，这说明基金经理正在肥自己的腰包。过度交易导致经常出现大量税单。突然产生异常回报……"（第9章点评）

## I — 自述

费用是唯一可预测且被复利放大的变量，故排第一；业绩最不可预测，排最后。过费用关后查四特征：经理自己重仓、敢与指数不同、不夸大回报、规模膨胀前关门谢客。业绩只在满5年且非单边大牛市期才可比——牛市冠军多半靠押注热点加运气，出名即遭资金洪水；但"昨天的输家几乎从未成为明天的赢家"，长期垫底且高费者剔除。真正卖出信号是四个结构性变化，一两年跑输不是（Sequoia 29年中41%年份跑输仍赚125倍）。

## A1 — 书中案例

- 曼哈顿基金（转述案例，第9章表9-2）：1965年设立、启动资本2.47亿美元，1967年收益38.6%（标普11%），此后连年惨败；1969年底重仓股中两家随后6个月内破产申请。
- 1999年最热10家基金（演算示例，第9章点评图9-1）："实际上，是有史以来年收益率最高的基金。但是，随后的3年使得1999年的巨大增值都被抹杀了。"

## A2 — 触发场景

1. 问"这只基金近三年翻倍，能不能买""帮我从这几只里选一只"。
2. 问"我的基金跑输指数一年了，要不要换"。
3. 问"主动基金还是指数基金""经理跳槽了怎么办"。
4. 按排行榜/五星评级想直接申购。
- Trigger：选基、申购赎回、基金经理、费率、回撤、晨星评级；fund selection、expense ratio、star rating、performance chasing。
- 区分：股债比例另有配置卡；收费顾问核查另有投顾尽调卡；本卡对象是基金产品与经理。

## E — 执行步骤

输入契约：候选基金总费率、持仓与宽基指数重合度、经理任职与自持份额、规模变化与是否关闭申购、≥5年业绩及同期大盘走势、历年税单/换手。

1. 费用过滤：按类别上限剔除（数值见R段，跨市场先重标定并注明）。完成标准：列出各候选总费率与是否超限。
2. 结构审查：经理自持≥1%？持仓与宽基雷同？靠广告拉客或规模膨胀仍开门？完成标准：四特征逐项通过/不通过。
3. 业绩最后看：取≥5年且非单边牛市期；业绩榜首记为危险信号；长期垫底且高费者剔除。完成标准：给出"可参考/不可参考"及理由。
4. 买入前自检：能否承受至少3年亏损，不能则不买。完成标准：用户明确回答。
5. 持有期监控四信号：策略突变、费用上升、频繁大额税单、突发异常回报——命中任一才启动卖出复核。完成标准：每次复查输出四信号状态。

输出契约：候选基金过滤表（费用/四特征/业绩口径/结论）＋持有监控信号清单。

## B — 边界

1. 封闭式折价10%–15%规则适用面窄：美股封闭式股基已萎缩，A股几乎绝迹，须按当期数据核验。
2. 费率上限为2003年美国数值，9%销售费、税单信号亦为美国制度；可迁移的是"先费用后业绩"顺序、四特征与四卖出信号。
3. "输家几乎从未翻身"不可反推为"赢家会一直赢"，业绩冠军反而是警戒。
4. 本卡不回答配多少比例买基金，也不核查收费顾问本人（另见投顾尽调卡）。
