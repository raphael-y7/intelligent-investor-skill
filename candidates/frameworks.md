# frameworks.md — 《聪明的投资者（第4版注疏点评版）》框架/流程候选（阶段1：framework-extractor）

- id: f01
  title: 防御型/积极型投资者自我定位决策框架
  type: framework
  source_chapter: 第4章点评（防御型投资者的投资组合策略）
  source_quote: |
    "这两种方式同样明智，无论采取何种方式均可取得成功。但前提是，你必须对自己有深入的了解，从而采用适合自己的方式，并在自己的整个投资生涯中坚持下去，而且善于控制自己的投资成本和情绪。"
  summary: |
    投资路线的第一决策不是选证券，而是确认自己是哪种投资者：取决于愿意投入的时间、精力和性格，
    而非年龄或风险偏好（导言：防御型求安全省事，积极型愿花大量时间精力换取超额回报）。
    兹威格进一步给出以"生活基本环境审视清单"代替"100减年龄"公式：婚姻子女、学费、继承赡养、
    工作受利率/油价影响、现金需求、可承受亏损，逐项核对后再定股债比例；想100%持股须通过六项测试
    （备好一年生活费、20年坚持、熊市中未卖且加买、已执行行为约束计划等）。
  inputs:
    - 可投入研究组合的时间与精力
    - 生活基本环境（家庭、收支、工作稳定性、现金需求）
    - 过往熊市中的实际行为记录
  outputs:
    - 防御型或积极型的明确选择（书中强调二者之间不存在中间地位）
    - 债券/现金占比区间（25%～75%）
  steps:
    - 按导言定义判断：只求省心安全→防御型；愿投入大量时间精力选股→积极型
    - 审视生活基本环境清单（单身/已婚、子女学费、继承与赡养、工作风险、是否靠投资收益补贴开支、可承受多大亏损）
    - 依结果确定股债比例：可承受较高风险→债券现金最低25%；否则最高75%
    - （可选）全仓持股前逐项通过"六项测试"（一年生活费、20年坚持、历经过熊市未恐慌卖出、熊市中买入、已读第8章并执行行为约束计划）
  missing_conditions:
    - 书中未给出量化的风险承受力问卷，比例最终仍取决于个人性格与态度的主观判断
  tags: [decision, asset-allocation, self-assessment, defensive-investor]

- id: f02
  title: 股债对半开与25%～75%区间的再平衡规则
  type: framework
  source_chapter: 第4章 防御型投资者的投资组合策略
  source_quote: |
    "因此，我们将向读者提出（两种投资）对半开的规则，尽管它看起来似乎过于简单。根据这一规则，投资者应在其实际操作中，保持对债券和股票的均等投资。比方说，如果股价水平使股票投资的比例提高到55%，他们就应准备卖出十一分之一的股票，并将该笔资金投入债券，以恢复两者之间的均衡。"
  summary: |
    防御型组合的基本结构：股票占比不低于25%、不高于75%，标准配置为股债各半；
    市场涨跌使比例偏离时机械地反向操作恢复均衡（55/45时调回50/50）。其价值不在收益最大化，
    而在强迫投资者对市场变化做出反应、避免牛市越高越买，并提供"有事可做"的心理释放通道。
    兹威格建议以固定日程（约每半年）按单一客观标准再平衡，而非猜测市场走向。
  inputs:
    - 总投资资金与股、债两部分市值
    - 目标配比（标准50/50，区间25%～75%）
  outputs:
    - 再平衡交易指令（卖出超配资产、买入低配资产）
    - 恢复目标比例后的组合
  steps:
    - 确定股债目标比例（默认对半开；依信心与性格可在25%～75%间调整）
    - 定期检查实际比例（点评建议每六个月一次，选易记日期，或用401(k)自动平衡服务）
    - 股票涨至约55%→卖出十一分之一股票转投债券；跌至约45%→以十一分之一债券转投股票
    - 生活状态无重大变化即不再改动目标比例；不以预测市场为调整理由
  missing_conditions:
    - 5%的触发偏移为示例性幅度，书中未给严格的阈值或频率规则
  tags: [asset-allocation, rebalancing, procedure, defensive-investor]

- id: f03
  title: 美元成本平均法与指数基金自动组合
  type: framework
  source_chapter: 第5章点评（防御型投资者与普通股）
  source_quote: |
    "最为理想的美元成本平均法是投资于一组指数基金，从而将所有具有投资价值的股票和债券都一网打尽。这样的话，你就可以摆脱诸如预测股市的走向、了解哪些板块以及其中的哪些股票会表现最好之类的猜谜游戏。"
  summary: |
    定期定额投入（每月/季投入同等金额买股，导言称美元成本平均法是"程式投资"的应用）：
    市场低迷时同额买到更多股份，高位时更少，从而免于择时与选股错误。兹威格的现代版：
    以三只指数基金为标的（如月结余500美元中300投美国股指、100投外国股指、100投债券指数），
    建立永久自动导航组合，对所有市场问题回答"我不知道，也不在乎"；
    想自选个股者可用90%指数基金核心＋10%实验仓的结构（第14章点评）。
  inputs:
    - 每月/季可定投的固定金额
    - 目标资产类别（美国股、外国股、债券）
  outputs:
    - 自动化、免决策的分散化组合
    - 消除"何时买入"与"买什么板块"两类决策
  steps:
    - 约定每月（或每周/季）固定日期投入固定金额
    - 按预设比例分配到覆盖全部资产类别的低成本指数基金
    - 无论涨跌坚持执行：下跌时同额买入更多份额，不因恐慌停买，也不因牛市加大投入
    - 对一切市场预测问题以"我不知道，也不在乎"应对（已自动持有两类资产）
    - （扩展）自选个股部分不超过股票资金的10%，核心仍是指数基金
  missing_conditions:
    - 格雷厄姆提醒：在整体市场水平太高时不宜新启动美元成本平均方案（第3章）
  tags: [dollar-cost-averaging, index-fund, procedure, discipline, zweig]

- id: f04
  title: 市场先生——对待市场波动的心理框架
  type: framework
  source_chapter: 第8章 投资者与市场波动
  source_quote: |
    "假设你在某家非上市企业拥有少量（1 000美元）的股份。你的一位合伙人（名叫"市场先生"）的确是一位非常热心的人。每天他都根据自己的判断告诉你，你的股权价值多少，而且他还让你以这个价值为基础，把股份全部出售给他，或者从他那里购买更多的股份。"
  summary: |
    把每日报价拟人化为情绪不稳的合伙人"市场先生"：他的估价时而热情过度、时而恐慌过度，
    你仅在价格愚蠢时才与他交易，其余时间依据企业业务与财报独立判断。
    价格波动对真正投资者的唯一重要意义是大跌后给买入机会、大涨后给卖出机会；
    千万不要因为股价上涨而购买、因为下跌而抛售。兹威格的配套结论：不让市场先生成为主人，
    方法是把注意力集中到自己能控制的因素上（成本、预期、风险、税款、自身行为），而非相对业绩。
  inputs:
    - 每日市场报价
    - 投资者对企业内在价值/经营结果的独立估计
  outputs:
    - 交易决策：利用报价（贱买贵卖）或忽略报价（持有不动）
    - 与大众相反的操作定位
  steps:
    - 把报价视为合伙人"市场先生"的意见而非事实
    - 核对自己对该企业业务与财务报告的判断
    - 仅当报价明显高于/低于自估价值时卖出/买入；其余时间不理会行情
    - 绝不因价格上涨而买、因下跌而卖；以企业经营结果而非股价衡量投资成败
    - （点评扩展）自问"房子三问"：若不时刻核实房价，房子价值是否就不涨了——同理对待组合报价
  missing_conditions:
    - 框架依赖投资者能对内在价值形成独立估计；无法估值者应退回指数化/防御型路线
  tags: [mental-model, mr-market, behavioral-discipline, valuation]

- id: f05
  title: 投资/投机的判别标准与投机资金隔离规则
  type: framework
  source_chapter: 第1章 投资与投机：聪明投资者的预期收益
  source_quote: |
    "投资操作是以深入分析为基础，确保本金的安全，并获得适当的回报；不满足这些要求的操作就是投机。"
  summary: |
    格雷厄姆的三要素判别：透彻分析＋本金安全＋适当（而非超高）回报，缺一即投机。
    投资者据公认价值标准判断市价，投机者据市价定价值。投机并非违法但须隔离管理：
    兹威格给出赌徒式纪律——投机资金单开账户、不超过总资产10%、赢钱后考虑撤出而非加码，
    思想上永不让投机与投资混同；三种危险情形为自以为投资实则投机、无技能却认真投机、投入过多。
  inputs:
    - 一笔拟执行的证券操作
    - 对标的的分析深度、本金保障、预期回报
  outputs:
    - 该操作归类：投资 / 投机（或赌博）
    - 投机仓位上限与账户隔离安排
  steps:
    - 检验三要素：是否透彻分析、本金是否有保障、预期回报是否"适当"
    - 任一不满足→承认这是投机，不冠以投资之名
    - 投机操作单独立账户，上限为总资产的10%
    - 因上涨或利润激增想加大投机投入时，反而考虑把资金撤出投机账户
  missing_conditions:
    - "适当回报"的量化水平随利率环境变化（格雷厄姆以当期高等级债券收益率为参照）
  tags: [definition, investment-vs-speculation, risk-control, discipline]

- id: f06
  title: 择时法与估价法二分框架（含"赚钱方法自我衰减"机制）
  type: framework
  source_chapter: 第8章 投资者与市场波动
  source_quote: |
    "他面临着两种可能获利的方法：择时方法和估价方法。我们所说的择时，是指努力去预知股市的行为——认为未来走势会上升时，购买或持有股票；认为未来走势会下降时，出售或停止购买股票。我们所说的估价是指尽力做到：股票报价低于其公允价值时买入，高于其公允价值时卖出。"
  summary: |
    从市场波动获利的两条路径：择时（预测走势）与估价（对照公允价值买卖）。
    以预测为基础的择时最终使人沦为投机者；除非择时恰好与价值判断吻合（能以远低于卖出价的价格买回），
    否则对投资者无实际价值。配套机制认知：任何容易理解且被广泛采纳的赚钱方法（道氏理论、程式方案、
    一月效应等）会因流行本身而失效——"股市上的任何赚钱方法，只要它容易理解并且被许多人采纳，
    那么，这种方法本身就会因太简单、太容易而无法持久"。
  inputs:
    - 市场价格信号（走势/突破点）
    - 证券的公允价值估计
  outputs:
    - 买卖决策的依据归类：择时（拒用）或估价（采用）
    - 对流行交易系统的失效预期
  steps:
    - 判断决策依据是"预测市场会怎样"还是"价格相对价值如何"
    - 前者归为投机，放弃或限定在小额投机账户内
    - 后者执行：报价低于公允价值买入、高于卖出；防御型投资者至少确保买价不高
    - 评估任何"经过历史检验的系统"时，先问它是否已广为人知（被采纳即趋于失效）
  missing_conditions:
    - 公允价值的估计方法需另行借助证券分析（第11章起）与安全边际（第20章）
  tags: [decision, timing-vs-valuation, market-forecasting, anti-pattern]

- id: f07
  title: 防御型投资者普通股四项规则
  type: framework
  source_chapter: 第5章 防御型投资者与普通股
  source_quote: |
    "适当但不要过分分散化，你的持股数应限制在最少10只，最多30只不同的股票之间。你挑选的每一家公司应该是大型的、知名的，在财务上是稳健的。……针对这一平均数，其市盈率应控制在25倍以内；如果是过去12个月的利润，则应控制在20倍以内。"
  summary: |
    防御型选股的四条可执行规则：(1)持股10～30只适度分散；(2)每家均为大型、知名、财务稳健的公司
    （财务稳健的量化线：工业企业普通股账面价值不低于总资本一半，公用事业/铁路不低于30%）；
    (3)有长期连续付息记录（建议至少自1950年/约20年起）；(4)买价限制市盈率——过去7年平均利润
    的25倍以内，或过去12个月利润的20倍以内（该条几乎排除所有热门成长股，是有意为之）。
  inputs:
    - 候选股票的规模、行业地位、财务报表、股息记录、历史每股收益
  outputs:
    - 防御型普通股组合（10～30只，剔除高市盈率热门股与成长股）
  steps:
    - 限定持股数量于10～30只
    - 逐家检查：大型（资产/销售额规模）、知名（行业前1/4～1/3）、财务稳健（账面值占比）
    - 要求自1950年前后起连续支付股息（点评：如今可要求连续10～20年）
    - 以过去7年平均利润计市盈率≤25倍（或近12个月≤20倍）设买价上限
    - 组合建立后每年至多复查一次，无充分理由不作频繁变更
  missing_conditions:
    - "大型/知名"为含糊形容词，格雷厄姆承认标准有随意性，只求不违背公认含义
  tags: [stock-selection-skill, defensive-investor, screening, procedure]

- id: f08
  title: 防御型投资者七项统计筛选标准（含22.5乘积法则）
  type: framework
  source_chapter: 第14章 防御型投资者的股票选择
  source_quote: |
    "在每次购买证券时，都要使用一套标准，以确保：（1）公司过去的业绩以及当期的财务状况达到某一最低的标准；（2）利润和资产与股价之比达到某一最低的数量。……根据经验法则，我们建议，市盈率与价格账面值之比的乘积不应该超过22.5。"
  summary: |
    防御型"定量检验组合"的七条硬标准：①相当规模（工业年销售额≥1亿美元/公用事业总资产≥5000万美元）；
    ②财务强劲（工业流动比≥2、长期债不超营运资本；公用事业负债不超股权两倍）；③过去10年每年盈利；
    ④至少20年连续付息；⑤10年每股收益增长≥1/3（期初期末各用3年平均数）；⑥股价≤过去3年平均利润的15倍；
    ⑦股价≤账面值1.5倍，且市盈率×市净率≤22.5。整体要求：组合盈利价格比（市盈率倒数）
    不低于当期高等级债券利率。点评给出2003年对应阈值（3年平均市盈率约17倍以内）。
  inputs:
    - 个股财务数据：销售额、流动资产负债、债务、10年利润、股息史、股价、账面值
    - 当期高等级债券利率
  outputs:
    - 通过全部七条的合格股票清单（1970年道指30家中仅5家全过；标准普尔《股票指南》中约百种）
    - 组合平均市盈率约12～13倍
  steps:
    - 按七项标准逐条过滤候选股（任一不过即剔除；公用事业可去掉流动比标准）
    - 核对组合整体盈利/价格比≥当期AA级债券收益率
    - 满足标准者以分散化方式持有；替代方案为直接买指数基金
    - （点评更新）用筛选网站/EDGAR数据重算：以当期股价除以过去三年平均利润算市盈率，拒绝"远期市盈率"
  missing_conditions:
    - 各最低限额是"主观武断"的（格雷厄姆自述），需随通胀与市场规模更新
    - 金融类企业只能沿用市盈率/市净率标准，无专用指标
  tags: [stock-selection-skill, screening, quantitative, defensive-investor, procedure]

- id: f09
  title: 积极型投资者三种主动方法（双前提筛选）
  type: framework
  source_chapter: 第7章 积极型投资者的证券组合策略：主动的方法
  source_quote: |
    "为了在长时间内获得比一般投资更好的结果，一种选择或操作策略必须具备两项优势：（1）它必须能达到基本稳健所要求的客观或合理标准；（2）它必须有别于大多数投资者或投机者采用的策略。根据经验和研究，我们推荐满足这些标准的三种投资方法。"
  summary: |
    超额收益策略的准入双前提：客观稳健＋不随大流。据此推荐三个领域，各需不同知识与禀性：
    (1)不太受欢迎的大公司（低市盈率法：买道指中市盈率最低的6～10只，持有1～5年，1937～1969年检验显著跑赢；
    规避克莱斯勒式"高利润年份低市盈率"陷阱需加"股价低于过去平均利润"条件）；(2)购买廉价证券（见f10）；

    - 保护法：确保现值>市价的差额足以吸收最坏情况，只要求企业持续经营

    是否已用分散化/合约/成本平均预先约束行为）。配帕斯卡赌注原则："在不确定条件下做决定时，
    后果比可能性要重要得多"——只控制胜率不够，必须控制出错后果；只要始终分散化且不重仓追逐新宠，
    错误的后果就永远不会是灾难性的。

    - 拟进行的投资决策
    - 决策者的经验记录、组合结构、行为约束工具
  outputs:
    - 信心校准结论（做/不做/缩小仓位）
    - 错误后果的可承受性评估
  steps:

    - 以"后果>可能性"权衡：即使胜率高，不可承受的后果也一票否决
    - 用分散化、投资合约、成本平均法把行为风险前置锁定
