# 牛市泡沫症状与新股免疫

## R — 原文

- "几乎所有的牛市都明显具备一些共同点，比如：（1）价格水平达到历史最高；（2）市盈率很高；（3）与债券收益相比，股息收益较低；（4）大量的保证金投机交易；（5）有许多质量较差的新普通股的发行。"（第8章）
- "最后，一些不知名的小公司的发行价，会高出那些已上市多年的中型公司的当期价格，这正是牛市开始由盛而衰的一个相当可信的信号。"（第6章）
- "投资者不能期望通过买任何新股或'热门'股（那些被人们认为可以迅速致富的股票），而获得优于平均水平的收益。"（第1章）
- "股市上的任何赚钱方法，只要它容易理解并且被许多人采纳，那么，这种方法本身就会因太简单、太容易而无法持久。"（第8章）
- 牛顿自叹"可以计算出天体的运动，却无法揣摩人类的疯狂"。（导言点评）

## I — 自述

把"牛市顶部"从预测问题变成观察问题：不猜点位，逐项核对五个可见症状——价格新高、整体高市盈率、股息率低于债券利率、保证金交易泛滥、劣质新股涌市。新股是最灵敏的温度计，发行有生命周期：牛市中途第一批定价尚可，越往后质量越差、要价越高，小公司发行价超过已上市中型股市价即是见顶信号。默认动作是免疫——新股含约7%承销折扣，内部人在发行价拿货，散户只能暴涨后接盘。配套心智：简单且流行的赚钱方法必自我衰减，"回测有效""新股必赚"不是买入依据；狂热感染的是性格而非智力——牛顿也中招。

## A1 — 书中案例

- VA Linux（转述案例，第6章点评）：1999年12月30美元发行，首日涨697.5%、市值127亿美元；此前5年销售共4400万美元、亏损2500万；2002年12月收盘1.19美元。
- AAA公司（转述案例，第17章）：1969年13美元发行、炒至28美元、市盈率115倍，1971年1月破产申请。
- 技术类新股统计（演算示例，附录7）：1968年45家"计算/数据/电子/科学/技术"公司，到1971年仅2家上涨、23家跌逾一半、12家除名。

## A2 — 触发场景

1. 问"现在是不是牛市顶部/泡沫，还能不能上车""指数新高要不要加仓"。
2. 晒新股/次新股首日暴涨，问打新、追入或中签后持有。
3. 身边人都在赚钱，犹豫要不要加大投入。
4. 拿"回测年化XX%"的必赚策略问可行性。
- Trigger：泡沫、见顶、打新、次新、热门股、追高、上车；bubble、IPO、new issue、hot stock、FOMO。
- 区分：市场整体估值与仓位倾向另有估值卡；本卡只做泡沫症状识别与新股/热门股默认免疫，不给点位、不判单笔操作属性。

## E — 执行步骤

输入契约：指数点位与历史比较、整体市盈率、股息率与高等级债券利率、保证金/两融余额、IPO数量与首日涨幅、小公司发行市盈率；缺项先向用户索取。

1. 症状检查表：逐项核对五症状，并标注新股发行生命周期阶段（第一批质优价吸引→量增质降→小公司天价）。完成标准：每项标"命中/不命中/数据缺失"并附证据。
2. 危险度分级：0–1项正常；2–3项警戒（停止加仓）；≥4项或小公司发行价超可比成熟股为高危。完成标准：给出命中证据链。
3. 新股参与决策：默认免疫；例外仅限积极型投资者且标的通过比存量证券更严的测试（多年盈利记录、财务稳健、买价合理）。完成标准：输出"免疫"或"放行＋理由"。
4. 方法失效预检：对用户提及的赚钱方法问"是否易懂且已广泛采纳"——是即预期衰减。完成标准：一句判定。

输出契约：泡沫症状检查表（症状/证据/命中）＋危险度分级＋新股决策结论。

## B — 边界

1. 症状提示危险但不能定时崩溃——格雷厄姆明言道指在下次下挫前可能再大幅超过900点；高危期动作限于三不纪律（不借钱、不加股票比重、减股至50%以下），不清仓择时。
2. 牛市中途第一批新股定价确有吸引力，但事前难与后批区分，对散户一律默认免疫，本卡不推荐个别新股。
3. 数据锚为1972/2003年美股；A股须以两融余额、换手率、新开户数、首日涨幅制度等当期指标重标定症状。
4. 不用于个股估值与买卖点位判断。
